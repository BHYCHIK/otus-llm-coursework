# Проект анализа отзывов на маркетплейс
## Определение тональности

Эксперименты показали, что лучше использовать для определения тональности
оригинальный (неочищенный) текст отзыва.
Для этого необходимо использовать настройку:
```
SKIP_REVIEW_FIX=true
```

Для определения тональности нужно использовать стандартную модель, сделанную для этого проекта:
```
SENTIMENT_DETECTION_MODEL=BHYCHIK/review-russian-sentiment-detection
```

## Получение хороших и плохих черт из отзывов

Для получения хороших и плохих черт используется
LLM по протоколу OpenAI.

- Скорость доставки
- Качество товара
- Цена товара
- Дизайн и внешний вид товара
- Функциональность товара
- Соответствие товара описанию
